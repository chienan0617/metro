# 捷運路網大亨 Metro Network Tycoon

> CA STUDIO 出品 · Vite + TypeScript · v1.0 完整營運系統

在多城市區域地圖上，由玩家自行選擇城市、規劃停靠順序、建設路線、配置列車並實際營運的捷運經營模擬遊戲。
完整實作 `docs/plan.md` 的全部階段（Phase 1–5）。

## 啟動方式

```bash
npm install
npm run dev        # 開發伺服器（預設 http://localhost:5173）
```

其他指令：

```bash
npm run typecheck  # TypeScript 嚴格型別檢查
npm test           # 單元測試（Vitest，76 項）
npm run build      # production build（輸出至 dist/）
npm run preview    # 預覽 production build
```

## 遊戲模式

- **生涯模式**：從 5 座城市與 $200 萬資金開始。載運旅客與完成任務可提升公司等級，逐步解鎖新城市、列車型號、車站升級與科技研究。任務與隨機事件引導成長節奏。
- **自由經營模式**：全部城市解鎖、起始資金 $500 萬，沒有任務壓力，適合自由規劃大型路網。

## 核心系統

### 地圖與路線
- **超大型區域地圖（7200 × 4800 世界單位）**，固定種子生成 **32–52 座城市**（核心都市、港口、工業、大學城、觀光、衛星城市、小鎮），城市間距拉長（典型相鄰距離 260–600 公里）；同一 seed 完全重現。
- **四種地理樣式**，可在主選單直接選擇或依種子自動決定：
  - **內陸大陸**（預設）：陸地比例可達 9 成以上，僅有內陸湖泊與內灣，城市散布在廣闊內陸。
  - **大陸海岸**：單側海洋、內陸延伸至地圖邊緣。
  - **海峽雙陸**：兩塊大陸隔著海峽，跨海建設成本最高。
  - **海島**：四面環海的大陸。
- 地形包含水域、海岸、平原、丘陵與山地，直接影響路線建設成本與城市類型分布；列車最高時速提升（75–260 km/h）以適應更長的路線。
- 玩家自行依序點選停靠城市規劃路線；即時顯示距離、建設成本（依地形倍率）、服務人口、單程時間與轉乘資訊。
- 路線管理：改名、改色、暫停／恢復營運、發車間隔（3–30 分鐘）、刪除（二次確認）。

### 乘客與經濟（每小時模擬）
- **OD 重力模型**：依城市人口、產業結構、城市類型、距離阻抗、時段（24 小時曲線）、平假日與事件產生城際需求。
- **路徑搜尋**：以車站、路線為節點的加權圖（Dijkstra），計入行駛時間、候車時間與轉乘懲罰；乘客可跨路線轉乘。
- **容量限制**：路線運能 = 車隊容量 × 班距；超額需求列為未滿足，不會產生收入。
- **票價**：起跳價 + 每公里計費；收入逐小時入帳，每日彙總。
- **服務品質**：平均候車、旅程時間、轉乘次數、載客率、未滿足比例、車站滿意度（會回饋影響需求）。

### 車隊與營運
- 6 種列車型號（價格／容量／速度／能源／維護／舒適度不同），可購買、指派、解除、賣出（六成退款）、升級（Lv.3，提高容量降低能耗）。
- 列車自動運行：行駛、停站、端點折返、依發車時刻調度；多輛列車自動均勻分布穩定班距。
- 成本：能源依里程計費（含列車等級與科技折扣）、維護費每日結算（含待命列車）、車站營運成本每日結算。

### 成長與內容
- **公司等級**：XP 來自載客與任務；升級解鎖城市（依距起始核心的距離分級）與新型列車。
- **任務**：程序化生成（含可行性檢查），主要＋附加目標、1–3 星評價、金錢與 XP 獎勵；完成後自動產生新任務。
- **科技研究**（等級 2 解鎖）：列車／車站／營運三條研究線各三階，需要費用與研究天數，效果即時生效。
- **車站升級**：Lv.3，提高容量、商業收入與滿意度。
- **隨機事件**：展覽、學期、節慶、能源漲價、施工、新商業區；影響需求、成本與容量，皆有期間與通知。
- **城市成長**：人口依成長率逐日變化，事件可加速。

### 時間、存檔與體驗
- 遊戲時鐘（年／月／日／星期／時分）、暫停與 1×／2×／4×；固定步進模擬，不受幀率影響。
- 存檔 v3：完整保存世界變更（城市人口與解鎖、車站等級／滿意度／統計）、路線統計、列車（含升級）、研究、事件、任務、財務歷史與通知；v1／v2 舊存檔自動升級。
- 自動存檔（節流＋定期）、手動存檔、匯出／匯入 JSON 備份、清除存檔（二次確認）。
- 設定：音效、震動回饋、降低動畫、地圖樣式與面板版面（與存檔分開保存）。
- **彈性 UI**：右側資訊面板可**拖曳調整寬度**、可用地圖右緣的浮動開關**收合**（收合後地圖佔滿版面，選取城市／路線時自動展開）；窄螢幕（≤920px）時面板改為**底部抽屜**、工具列只顯示圖示、頂部資訊列可橫向滑動，讓互動地圖在手機或任何平台都維持最大面積。
- 新手引導：依實際進度打勾的學習清單；完整操作說明與新手提示。
- 音效以 WebAudio 產生（無外部檔案）；重要操作有音效與震動回饋（可關閉）。

## 操作說明

| 操作 | 說明 |
|---|---|
| 左鍵拖曳 | 平移地圖 |
| 滾輪 / 雙指 | 縮放（以游標位置為中心） |
| 點擊城市／路線 | 查看資訊（含車站營運、升級與路線績效） |
| 建立路線模式：點擊城市 | 依序加入停靠站；右鍵復原上一站 |
| 空白鍵 | 暫停／繼續營運 |
| 0 / 1 / 2 / 4 | 切換模擬速度 |
| Esc | 取消建設 / 關閉目前面板 |

### 建議流程

1. 建立第一條路線（連接 2–3 座相鄰城市）。
2. 車庫購買列車並配置到路線；班距越短運能越高。
3. 按 ▶ 開始營運，到「財務」面板觀察收支；「任務」面板追蹤目標。
4. 提升載客：增加列車、升級車站、連接新城市（等級解鎖）。
5. 用研究降低成本、擴大運能；留意事件帶來的機會與風險。

## 專案結構

```
src/
  core/      共用型別、可重現亂數、數學與格式工具、狀態容器
  world/     地形與城市生成（固定 seed 可重現）
  game/      遊戲邏輯：時間、經濟、路線、車隊、需求、路網、車站、
             研究、任務、事件、成長、模擬核心、存檔（與 UI 完全分離）
  ui/        畫面層：Canvas 地圖、面板、選單、設定與音效
  styles/    全站樣式
docs/plan.md 完整開發計畫
```

所有隨機內容由 seed 決定；平衡數值集中於 `src/game/config.ts`；模擬核心可獨立測試。

## 已知限制（刻意簡化）

- 乘客以群組流量模擬（非個別乘客物件），列車載客以路線運能與平均負載呈現。
- 施工時間簡化為即時完工；列車物理以抽象時間模型呈現。
- 列車維修狀態與耐久度欄位已預留但尚未實際運作。
- 每座城市一個主要車站（資料模型已預留多站擴充）。
- 未支援雲端存檔與多人連線（規劃外）。
